# MASA Database Automated Backup Service

Windows background service executing scheduled differential and full database backup snapshots.

## Overview
MASA Database Automated Backup Service is an enterprise-grade software component designed and optimized for performance, scalability, and seamless user interaction. Built adhering to modern software engineering paradigms and SOLID design principles, this project delivers reliable execution across Windows environments.

## Architecture and Design
- Layered Architecture: Distinct separation between business logic, data persistence, and presentation layers.
- Optimized Resource Utilization: Lightweight memory footprint and responsive asynchronous execution.
- Modern User Experience: Modern typography and curated design palette.
- Resilient Error Handling: Structured exception logging and defensive programming standards.

## Prerequisites
- Operating System: Windows 10 / Windows 11 / Windows Server 2019+
- Runtime Environment: Microsoft .NET Framework 4.5+ or .NET Core / 8 Runtime
- Development Tools: Microsoft Visual Studio 2019 / 2022, or MSBuild Command Line

## Build and Execution
1. Clone the repository:
```bash
git clone https://github.com/XREFS0/masa-database-backup-service.git
```
2. Restore dependencies and compile:
```bash
msbuild /p:Configuration=Release
```
3. The compiled binary will be generated inside the standard Release output directory.
